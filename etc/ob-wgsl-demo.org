#+title: Literate GPU shaders: ob-wgsl demo
#+startup: showall

NeoMacs renders =wgsl= and =glsl= org-babel blocks as *live animated GPU
surfaces* right below the block — a literate shader document.  See
=docs/display-engine/SHADER_SURFACES.md= for the shader contract and
=lisp/ob-wgsl.el= for how results are displayed.

To run this file inside the NeoMacs GUI:

#+begin_src emacs-lisp
;; Enable the wgsl/glsl babel backends (also enables C-c ' editing in the
;; shader playground mode) and stop org from asking before each compile.
(require 'ob-wgsl)
(setq org-confirm-babel-evaluate nil)
#+end_src

Then press =C-c C-c= inside either shader block below.

- A successful compile puts a running surface at the block's =#+RESULTS=
  (the plain-text result line underneath is the TTY/export fallback; the
  GUI covers it with the live render).
- A *compile error* replaces the result with naga's full span-annotated
  diagnostics — try deleting a semicolon and re-running.  The previous
  surface is removed; fix the code and =C-c C-c= again.
- Re-execution destroys the old GPU surface and shows the new one.
- Killing this buffer frees every surface it created (and the handles
  are GC-managed besides, so nothing leaks either way).

* Animated WGSL plasma

WGSL blocks define =fn mainImage(fragCoord: vec2<f32>) -> vec4<f32>= and
read Shadertoy-style built-ins through the =u= uniform block (=u.iTime=,
=u.iResolution=, =u.iMouse=).  Each =:uniforms= entry generates an
accessor — =(speed . 1.5)= becomes =u_speed()= — and can be changed
live with =neomacs-surface-set-uniform= (no recompile).  Sizes come from
=:width= / =:height= (defaults 400 x 225).

#+begin_src wgsl :width 480 :height 200 :uniforms '((speed . 1.5))
fn mainImage(fragCoord: vec2<f32>) -> vec4<f32> {
    let uv = (2.0 * fragCoord - u.iResolution.xy) / u.iResolution.y;
    let t = u.iTime * u_speed();
    var v = sin(uv.x * 5.0 + t);
    v += sin(uv.y * 5.0 + t * 1.3);
    v += sin((uv.x + uv.y) * 5.0 + t * 0.7);
    v += sin(length(uv) * 7.0 - t * 1.7);
    let col = 0.5 + 0.5 * cos(3.14159 * v + vec3<f32>(0.0, 2.0, 4.0));
    return vec4<f32>(col, 1.0);
}
#+end_src

* Shadertoy GLSL template

GLSL blocks take the Shadertoy dialect unmodified — =void
mainImage(out vec4 fragColor, in vec2 fragCoord)= reading bare =iTime=,
=iResolution=, =iMouse=, =texture(iChannel0, uv)=.  This is Shadertoy's
default new-shader template, pasted verbatim; most Shadertoy and Ghostty
shaders work the same way (three real Ghostty ports live in
=lisp/neomacs-shaders.el= — try =M-x neomacs-shaders-ghostty-starfield=,
=-ghostty-gradient=, =-ghostty-crt=, and =M-x neomacs-shaders-off=).

#+begin_src glsl
void mainImage(out vec4 fragColor, in vec2 fragCoord) {
    vec2 uv = fragCoord / iResolution.xy;
    vec3 col = 0.5 + 0.5 * cos(iTime + uv.xyx + vec3(0, 2, 4));
    fragColor = vec4(col, 1.0);
}
#+end_src

* Notes

- =:channel0= feeds a texture to =iChannel0=: a variable holding another
  surface's handle, or a quoted ='(image :type png :file "...")= /
  ='(video :file "...")= spec.  Unbound channels sample transparent
  black.
- =:results silent= compiles (useful as a syntax check) but shows
  nothing; the surface is destroyed immediately.
- Shader blocks tangle to =.wgsl= / =.glsl= files like any babel
  language.
